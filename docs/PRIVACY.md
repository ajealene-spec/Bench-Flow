# Bench Flow privacy policy

Last updated 26 October 2026. The same text is shown in the app at /privacy.

**Your data stays on your device.** Bench Flow saves your protocols, experiments, notes, photos and settings in the device's local database (IndexedDB). There is no account to create or sign in to, and lab records are not copied to a server.

**No tracking or analytics.** Bench Flow has no advertising, analytics or tracking code.

**Optional AI features.** If you add your own Anthropic API key, the protocol text you ask about is sent to Anthropic so it can answer. The request goes through the Bench Flow server (hosted on Vercel), which passes it on and does not store your text or your key. Anthropic handles the request under its own terms. Without a key these features stay off.

**Optional protocols.io imports.** The app contacts protocols.io only when you ask it to import a protocol, and only for the protocol you name.

**Notifications, microphone and camera.** Timer alerts are local notifications created on your device, and the app asks permission first. The microphone and camera are used only when you use the feature that needs them.

**Contact.** Open an issue at https://github.com/ajealene-spec/Bench-Flow/issues
